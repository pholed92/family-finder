# 가족찾기 · 소리로 휴대폰 찾기

부모님 두 분이 서로의 휴대폰에 큰 소리와 진동을 울릴 수 있는 안드로이드 앱입니다. 갤럭시 S22·S26을 대상으로 큰 글씨로 준비했습니다.

휴대폰에서 APK를 받아 열고 설치하세요. 이전 버전 위에 업데이트할 수 있습니다. Android 8.0 이상, 최신 Android System WebView와 Google Play 서비스가 필요합니다.

## 1.1.0에서 바뀐 점

- 앱의 위치 공유·GPS·지도와 상시 서버 조회를 제거했습니다. 위치 공유는 Google Maps에서 따로 사용합니다.
- 소리 요청은 Google 푸시(FCM)로 받습니다. 요청을 받았을 때만 잠깐 소리 재생 서비스를 실행합니다.
- 진동 모드에서도 알람 음량을 올려 사이렌과 진동을 재생합니다. 최대 30초 뒤 중지하고 기존 알람 음량을 복원합니다.
- 주요 소리 버튼은 36px, 설명은 24~26px이며 부모님이 쉽게 누를 수 있게 크게 만들었습니다.
- 서버 연결 전에도 ‘이 휴대폰 소리 시험 · 5초’ 버튼으로 소리를 확인할 수 있습니다.

## 현재 사용 가능한 범위

**APK 설치와 이 휴대폰의 5초 소리 시험은 서버 연결 전에도 가능합니다. 가족 휴대폰에 원격으로 소리를 울리려면 Firebase 서버 인증과 HTTPS 서버 설정이 완료되어야 합니다.** APK만 설치하면 원격 푸시가 바로 연결되는 것은 아닙니다.

FCM 서버 설정이 완료되면 두 휴대폰에 같은 서버 주소를 입력하고 이름을 등록합니다. 한 휴대폰에서 만든 8자리 연결 번호를 다른 휴대폰에 입력한 뒤 첫 휴대폰에서 연결을 승인합니다. 두 휴대폰 모두 알림을 허용하고 ‘소리 받기’를 켜 주세요.

## 검증

APK 빌드·서명, 큰 글씨 브라우저 화면과 소리 푸시 서버 테스트 12개를 검사했습니다. 실제 S22/S26에서 진동 모드·잠금 화면·절전·원격 푸시 수신 검증은 필요합니다. 휴대폰이나 인터넷이 꺼져 있거나 앱을 강제 종료한 상태에는 요청을 받지 못할 수 있습니다. 방해 금지 설정에 따라 알람 허용이 필요할 수 있습니다.

서버는 최신 소리 요청과 연결한 가족 정보만 관리합니다. 위치를 저장하지 않으며 가족 승인과 기기 인증을 검사한 뒤 소리를 재생하도록 구성했습니다. 개인 키·기기 토큰·운영 데이터는 공개 파일에 포함하지 않습니다.
