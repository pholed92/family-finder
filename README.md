# 가족찾기

부모님 두 분이 서로의 휴대폰 위치를 확인하고, 잃어버린 휴대폰에 큰 소리와 진동을 울릴 수 있는 안드로이드 앱입니다. 갤럭시 S22·S26을 대상으로 큰 글씨 화면을 준비했습니다.

**[안드로이드 APK 받기 — 가족찾기 1.0.1](https://github.com/pholed92/family-finder/releases/download/v1.0.1/family-finder-1.0.1.apk)**

- [파일 SHA256 체크섬](https://github.com/pholed92/family-finder/releases/download/v1.0.1/SHA256SUMS.txt)

APK를 휴대폰에서 내려받아 설치하세요. 이미 1.0.0을 설치했다면 앱을 지우지 않고 업데이트할 수 있습니다. Android 8.0 이상과 최신 Android System WebView가 필요합니다.

## 부모님용 큰 글씨

- 제목: 36~40px
- 주요 버튼: 32px, 높이 88px 이상
- 본문·설명: 24~26px
- 연결 번호: 48px
- 휴대폰의 글자 크기를 더 크게 설정하면 앱도 추가로 확대됩니다.

## 처음 사용하기

1. 앱 서버를 운영할 가족에게 **HTTPS 서버 주소**를 받습니다. 서버는 두 휴대폰이 인터넷을 통해 연결될 수 있도록 준비해야 합니다.
2. 두 휴대폰에 같은 APK를 설치하고 각자 이름(예: 엄마/아빠)과 같은 서버 주소를 입력합니다.
3. 한 분이 연결 번호를 만들고 다른 분이 그 번호를 입력합니다. 첫 휴대폰에서 이름을 확인해 연결을 승인합니다.
4. 두 휴대폰 모두 위치 공유를 켜고 위치·알림 권한을 허용합니다. 배터리 사용은 제한 없음으로 설정합니다.
5. 시험 버튼으로 소리를 확인한 뒤 가족 휴대폰의 소리 울리기를 눌러 확인합니다.

## 기능

서로의 최신 위치·측정 시각·위치 오차를 지도에서 확인합니다. 위치 공유를 켠 휴대폰에는 최대 30초간 사이렌과 진동을 요청할 수 있고, 요청하거나 수신한 휴대폰에서 중지할 수 있습니다. 소리 재생 시작은 상대 휴대폰의 수신 확인 후 표시합니다.

서버는 최신 위치 한 개만 저장합니다. 위치 공유를 끄면 서버의 현재 위치를 삭제하며, 가족 연결에는 상대방 승인이 필요합니다.

## 확인된 범위

APK 빌드와 v2/v3 서명 검증, 큰 글씨의 브라우저 화면 검사, 서버 테스트 8개를 완료했습니다. 실제 S22/S26에서 설치·GPS·잠금 화면·절전·소리 동작을 확인해야 합니다.

휴대폰이나 서버가 꺼졌거나 인터넷이 끊기면 소리 요청을 받을 수 없습니다. 방해 금지와 기기 절전 설정에 따라 소리가 제한될 수 있습니다. 재부팅·강제 종료 후에는 앱을 열고 위치 공유를 다시 켜 주세요.

## 서버 설치

서버 ZIP 안의 안내를 확인하세요. Node.js 22 이상을 사용하며 별도 npm 패키지 설치는 필요 없습니다. 기본 서버는 loopback에 바인딩하고, 외부 연결에는 유효한 HTTPS 주소와 프록시를 사용합니다. 기존 서비스가 사용하는 포트는 유지하고 앱 서버에 빈 포트를 지정할 수 있습니다.

이 저장소는 APK와 서버 설치 묶음을 배포합니다. 앱 서명 개인 키, 비밀번호, 운영 설정, 실제 가족 이름·위치·기기 토큰은 공개 파일에 포함하지 않습니다. 앱 지도 라이브러리 Leaflet의 라이선스는 APK에 함께 포함되어 있습니다.
